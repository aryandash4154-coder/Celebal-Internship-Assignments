# Week 3 – SQL Sales Analysis

## Project Overview

This project analyzes the Superstore Sales dataset using SQL. The objective is to apply Subqueries, Common Table Expressions (CTEs), Window Functions, and JOIN operations to solve business-related queries and generate meaningful insights.

## Tools Used

- MySQL Workbench 8.0
- Superstore Dataset
- Microsoft Word


## SQL Concepts Used

- Subqueries
- Common Table Expressions (CTEs)
- Window Functions (ROW_NUMBER and RANK)
- JOIN Operations
- Aggregate Functions
- GROUP BY
- ORDER BY

## Business Queries

- Orders with above-average sales
- Highest order per customer
- Total sales per customer
- Average profit per customer
- Customer ranking
- Top 10 customers
- Lowest 10 customers
- Single-order customers
- Customers with above-average total sales

## Project Outcome

The project demonstrates how SQL can be used to organize, analyze, and extract meaningful business insights from sales data using advanced SQL techniques.
